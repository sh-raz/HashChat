
# HashChat (iOS)

A simple iOS chat app built with UIKit/Swift + Firebase (Auth, Firestore, Storage). Keyboard handling via IQKeyboardManagerSwift.

## Requirements
- Xcode 16+
- iOS 13.0+ deployment target
- Swift Package Manager (SPM)

## Dependencies (SPM)
Add in Xcode → **Project** → **Package Dependencies**:
- `https://github.com/firebase/firebase-ios-sdk`  
  - Products: **FirebaseAuth**, **FirebaseFirestore**, **FirebaseStorage** 
- `https://github.com/hackiftekhar/IQKeyboardManager`  
  - Product: **IQKeyboardManagerSwift**
